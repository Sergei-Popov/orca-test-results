## [0.1.0] - 2026-11-17

### Added

- A sidebar panel for locally generated JUnit XML. Choose a workspace, load a report by path, or open the newest report found in a supported location.
- Counts of passed, failed and skipped cases, with assertions and output for up to 100 failures.
- Source navigation from Node.js reporter file attributes and pytest tracebacks, plus a shortcut to the original XML.
- An editable agent handoff with the selected test, workspace, report, source and optional rerun command.
- English and Russian controls, an original listing icon and a gallery of the native panel.
